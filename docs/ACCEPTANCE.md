# 系统验收说明

本文记录毕业设计的验收入口和验证范围。自动回归使用隔离数据，手动演示使用工作台中的资料。

## 自动验证

在项目根目录执行以下命令。

    .\.venv\Scripts\python.exe -m pip check
    .\.venv\Scripts\python.exe -X utf8 .\scripts\verify_system.py
    Set-Location .\frontend
    npm.cmd run build

| 检查内容 | 预期 |
|---|---|
| 健康检查 | 200 |
| 未登录访问业务接口 | 401 |
| 普通用户访问知识库管理 | 403 |
| 普通用户修改工单状态 | 403 |
| 上传 DOCX 后人工修改并切分 | 返回编辑后的正文片段 |
| 确认入库并重试 | 相同文档编号 |
| 真实 BGE、Chroma 检索 | 找到含修改内容的来源 |
| 问答保存与重复提交 | 保存一轮并返回原结果 |
| 其他账号读取会话或工单 | 404 |
| 工单关联会话 | 快照中含问题、回答和引用 |
| 客服状态流转 | 用户最终看到已完成 |
| 删除知识文档 | SQLite 片段与 Chroma 向量均被清理 |
| 历史问答与工单 | 删除文档后仍可回看已保存快照 |
| 退出后的令牌 | 401 |

默认回归用真实本地 Embedding 和向量索引，DeepSeek 使用接口替身，因此其通过结果覆盖业务流程和接口协议。

## 实网验证

    .\.venv\Scripts\python.exe -X utf8 .\scripts\verify_system.py --live

该模式从后端 .env 读取密钥和模型配置，向 DeepSeek 发起一次虚构资料问答。通过后，终端应显示模型模式为 DeepSeek 实网。密钥为空时会停止，并提示先完成配置。

## 浏览器验收

按 docs/DEMO.md 完成上传、人工修改、引用问答、会话建单、客服处理和删除。再检查以下行为。

- 刷新后可恢复登录、会话和工单。
- 未提交的正文和片段草稿只保存在当前页面。
- 普通用户和客服拥有不同的操作入口，后端也校验权限。
- 取消聊天重试后可以修改问题。网络失败后继续重试会保留请求编号。
- 旧浏览器数据认领后，聊天和工单显示在当前账号下。
- 索引或删除失败时，可在文档列表继续处理。
