# 答辩演示流程

这份流程用于展示智能客服知识库与售后工单系统的完整业务链。演示资料为虚构售后规则，建议在演示前完成依赖安装和模型缓存。

## 准备

1. 按项目 README 安装依赖，配置后端 .env。
2. 在 backend 目录运行 python -m app.create_staff --username support 创建客服账号。
3. 在根目录运行 scripts/create_demo.py，生成 examples/售后政策演示.docx。
4. 启动前后端。在登录页注册 demo_customer 普通用户，密码自行设置。
5. 运行默认回归。需要真实回答时，配置 DeepSeek 后运行 scripts/verify_system.py --live。

测试脚本的临时账号不会出现在正式数据库中。

## 客服维护知识

1. 用客服账号登录，进入知识库管理，点击上传文档。
2. 上传生成的 Word 样例，检查正文中的七天退货规则。
3. 人工将七天改为十五天，点击预览切分。
4. 核对片段，点击确认入库，等待显示文档编号。
5. 返回文档列表，确认状态为已索引，打开详情核对十五天。

这部分展示上传解析、人工审核、片段存储、向量化和索引状态。

## 用户问答与引用

1. 退出客服账号，用普通用户登录。
2. 提问「签收后几天内可以申请退货？」
3. 查看回答下方的文件名、片段编号和原文，确认引用包含十五天。
4. 刷新页面，检查历史会话与引用仍然存在。

回答仅供参考。演示时以引用原文人工核验，实际输出取决于模型响应。

## 从会话转工单

1. 在当前聊天页点击基于当前会话创建工单。
2. 将标题写为退款进度核实，在描述中说明虚构订单 DEMO-001 的问题。
3. 提交后检查待处理状态、描述和建单时的会话上下文。
4. 再在工单页手动创建一张物流咨询工单，展示两种建单方式。

## 客服处理

1. 退出普通用户，登录客服账号。
2. 在售后工单页查看用户工单，筛选待处理。
3. 打开退款工单，核对问题和引用快照，依次点击开始处理和标记完成。
4. 普通用户再次登录，确认自己的工单状态为已完成。

## 删除与权限

1. 客服删除本次演示上传的文档，确认列表中已移除。
2. 普通用户新建会话，重复退货问题。只有这份资料时，系统提示资料不足。
3. 展示普通用户导航和客服导航的差别。
4. 在接口文档说明未登录返回 401、普通用户调用管理接口返回 403。

已有其他资料时，检索可能返回其他已索引文档。历史聊天和工单快照可继续用于回看。

## 讲解要点

- Vue 负责展示、人工编辑和确认。后端负责持久化、检索与模型调用。
- SQLite 保存用户、消息、工单、文档和片段原文。Chroma 通过片段 ID 保存向量。
- BGE 在本地 CPU 上懒加载，DeepSeek 通过后端配置调用。
- 文档确认、聊天和建单通过请求编号处理重试。状态更新检查版本，避免覆盖更新。
- 资料进入知识库需要人工确认，引用用于核验回答。
- 系统采用本地单体分层结构，适合本科毕业设计演示。
